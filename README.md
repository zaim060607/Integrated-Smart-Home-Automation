# Integrated Smart Home Automation & Security Ecosystem

An IoT-based smart home automation and security project developed using Arduino C++ and simulated in Wokwi.

## Features
- Automatic temperature monitoring and cooling control
- LDR-based intelligent lighting
- PIR motion detection and security alerts
- Servo-controlled automatic door
- Normal and Armed security modes
- Buzzer alerts and LED indicators
- Non-blocking control logic using `millis()`

## Technologies
Arduino Uno, Arduino C++, Wokwi Simulator, Temperature Sensor, LDR, PIR Sensor, Servo Motor, LEDs, and Piezo Buzzer.

## Implementation Note
The tested simulation uses Arduino Uno. ESP8266 NodeMCU is the proposed hardware implementation and has not been experimentally verified.
