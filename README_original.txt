READY-WIRED WOKWI SIMULATION (NOT TINKERCAD IMPORT)

Open https://wokwi.com/projects/new/arduino-uno
Paste diagram.json in the diagram.json tab (replace all).
Paste sketch.ino in the sketch.ino tab (replace all).
Press Play.

Click temperature sensor to change temperature, light sensor to change light, PIR to simulate motion. Use blue doorbell and red security buttons.

Notes: Wokwi uses NTC temperature module rather than Tinkercad TMP36. LDR is Wokwi 4-pin sensor module with internal divider rather than bare 2-pin photoresistor. This is a simulator-specific equivalent.
